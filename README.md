# RESCENE Community Token

Static website for the RESCENE community token project.

## Deploy to Vercel

Import this repository in Vercel and set the project root to `.` (the repository root). No build command or output directory is needed; Vercel can serve `index.html` and the site assets directly.

## Local preview

Serve this directory with any static HTTP server, then open the local URL it prints. For example, with Python installed:

```sh
python -m http.server 8000
```

The site uses Base mainnet contract addresses configured in `chain-config.js`.
